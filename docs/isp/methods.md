# 方法・共通設定（詳細）

このページでは、各臓器の in silico perturbation に共通する **設定** を解説します。

## 1. 基本フロー（チュートリアル準拠）

Geneformer 公式チュートリアル（`examples/in_silico_perturbation.ipynb`）に従い、以下 3 ステップで実施：

1. **状態 embedding 抽出** — `EmbExtractor.get_state_embs()` で、疾患（AD/PF）と健常（WT）の状態 embedding を計算（タイムポイントごとに 1 回、全遺伝子で共有）。
2. **仮想遺伝子削除** — `InSilicoPerturber.perturb_data()` で 1 遺伝子ずつ `delete` した変異細胞 embedding を生成。
3. **統計** — `InSilicoPerturberStats.get_stats()`（`mode="goal_state_shift"`）で `Shift_to_goal_end` を算出。

### 計算制約（3 台の PC で検証済み）

- **`datasets` は 4.x 必須**。`datasets>=5` だと `InSilicoPerturber.perturb_data` の `dataset.map()` がハングします。
  `uv pip install datasets==4.0.0`
- **`nproc=1` が検証済みの安定デフォルト**。`nproc>1` は datasets<5 かつ小さなデータセットでのみ安全（フォワードパスと RAM 競合）。
- **`max_ncells` は控えめに**。`perturb_data` は全変種データセットを RAM に実体化（~n_cells × variants × seq_len）。2000 細胞で MPS ホストは OOM。
- `estimate_perturb_ram()` で RAM 見積りを表示。

## 3. 1 遺伝子ずつ削除する理由

`combos=0` の状態で遺伝子リストを `genes_to_perturb` に渡すと、
`perturb_data` が「全リストの遺伝子を同時に持つ細胞」でフィルタします
（`filter_data_by_tokens`: intersection == len(tokens)）。細胞型特異的遺伝子が混ざると
この条件は空になります。正しい方法は **combos=0 で 1 遺伝子ずつ** 実行し、
各遺伝子の `Shift_to_goal_end` を個別に集めることです。

## 4. 解釈

- **`Shift_to_goal_end > 0`（正・大きい）**: この遺伝子を削除すると疾患細胞が WT に近づく
  → **早期発症の駆動因子 / 介入標的候補**。
- **`Shift_to_goal_end < 0`（負・大きい）**: 削除で WT から遠ざかる = この遺伝子は健常状態の
  維持に寄与。削除は逆効果（CD8A など基底差を反映）。
- 絶対値が小さい遺伝子は微小値に固まるため、`max_ncells` を上げて再スクリーニングが有用。
- **注意（モデル依存）**: 同じデータでもモデルを替えると順位は変わる。104M と 316M を比べた追試では、
  55 遺伝子のうち 18 個で符号が反転した（差の大きさは計算誤差の約 7 倍）。
  上の「正 = 介入標的候補」は 1 つのモデルの結果であり、単独では暫定として扱う
  （[遵守項目](checklist.md) B 章）。
- **注意（発現量）**: 削除できる細胞が少ない遺伝子は値が意味を持たない。遺伝子ごとに
  「摂動できる細胞数」を併記し、500 未満は順位を解釈しない（E4）
  （[合格基準](criteria.md)）。

## 6. モデル解決

ファインチューン済みセル分類器は `runs/TRAINED_MODEL_PATH.txt` を参照しますが、
**他ホストで生成された絶対パス**（例：thinkstation3 の `/home/thinkstation3/...`）を指すことがあり
ローカルでは無効です。`_isp_common.resolve_classifier_dir()` は以下の順で解決：

1. `CELLCLASSIFIER_DIR` / `IS_CELLCLASSIFIER_DIR`（env 指定）
2. `runs/TRAINED_MODEL_PATH.txt` のパスが存在する場合
3. ローカル `runs/**/ksplit*` の最新チェックポイント
4. プリトレーン済み `Geneformer-V2-104M`

これにより **どの PC で実行しても同じ出力**が得られます。

## 7. 用語の定義（操作と統計量）

**この節は、ISP の操作と統計量の定義をまとめたものです。** 用語の一覧（使う表記と使わない表記）は
[記述ルール](style-guide.md) の A-1 が正です。この節はその定義の中身を書きます。
初出で意味を添えるときはこの文をそのまま使えます。

| 用語 | 定義 |
|---|---|
| 削除（delete） | その遺伝子のトークンを細胞の入力から取り除く操作です。取り除いた遺伝子自身の埋め込みは比較の対象から外します。 |
| 過剰発現（overexpress） | その遺伝子のトークンを順位符号化の先頭へ移す操作です。発現量そのものを増やすのではなく、順位を先頭に置きます。 |
| トークン | モデルが遺伝子を扱う単位です。1 遺伝子が 1 トークンに対応します。 |
| 順位符号化（rank value encoding） | 1 つの細胞を、発現量の多い順に遺伝子を並べた列として表す入力形式です。 |
| コサイン類似度 | 2 つのベクトルの向きの一致度です。1 で同じ向き、0 で直交します。 |
| 移動度（movement） | 操作の前後で遺伝子の埋め込みベクトルがどれだけ動いたかです。`1 − コサイン類似度` で計算し、1 に近いほど大きく動いたことを表します。`Shift` の別名として使いません。 |
| 検出率（detection rate） | 対象の細胞のうち、その遺伝子を持っている細胞の割合です。 |
| 摂動できる細胞数 | その遺伝子を持っていて、実際に操作の対象になった細胞の数です。 |
| 対照遺伝子（control gene） | 対象と同じ細胞で同じ操作を行う遺伝子です。操作そのものが生む移動度の水準を測るために置きます。選び方は §7-1 です。 |
| 対照の水準（control level） | 対照遺伝子を操作したときに生じた移動度の最大値です。1 遺伝子だけの値であり、ばらつきを持ちません。 |
| null 分布（null distribution） | 順位位置を対象に合わせた 20 個以上の遺伝子（null 遺伝子）を同じ操作で動かしたときの移動度の分布です。偶然の範囲を決める基準になります。定義は §8 です。 |
| z 値 | 移動度が null の平均から標準偏差いくつ分離れているかを表す値です。 |
| p 値 | その値以上に動く遺伝子が偶然出る確率です。片側で数えます。 |
| q 値 | p 値を Benjamini–Hochberg 法で補正した偽発見率（false discovery rate）です。 |
| 共発現（co-expression） | 同じ細胞で同時に発現しやすい遺伝子どうしの関係です。 |
| 位置ずれ（positional shift） | 削除により、その遺伝子より後ろの順位が 1 つずつ前にずれることです。上位遺伝子が位置ずれだけで決まっていないかは別に検証します。 |
| 細胞全体の埋め込みの動き | 細胞を表す 1 本のベクトル（CLS トークン）が操作でどれだけ動いたかです。検出率の影響を受けるため、遺伝子の重要性の指標にはしません。 |
| 根拠の種類（A、B、C） | A は自データの実測、B は他データからの借用、C は未確立です。合否の線に使えるのは A だけです（[記述ルール](style-guide.md) A-2）。 |
| プール | 解析の対象にした細胞型の集合です。このページでは「悪性細胞のプール」のように使います。 |

**数値の表記**: 移動度と null の値は有効数字 3 桁で書きます。
0.01 以上は小数で書き（`0.113`）、0.01 未満は指数表記で書きます（`4.80e-03`）。
`Shift` のような非常に小さい値は常に指数表記です（[記述ルール](style-guide.md) C-2）。

### 7-1. 対照遺伝子の選び方

対象遺伝子と同じ 400 細胞で、次の条件を満たす遺伝子を選びます。

1. その実行の細胞にできるだけ多く含まれること（検出率の高い順に候補を並べます）。
2. 対象遺伝子の実行で上位 50 位以内に入っていないこと（応答そのものを対照にしないため）。
3. その遺伝子の操作自体が仮説になっているものでないこと（ドライバー、上皮マーカー、上位に出た遺伝子）。
4. 上から順に見て、条件を満たした最初の遺伝子を採用します。

**限界**: 対照は 1 遺伝子なので偶然のばらつきを測れません。また、順位位置が対象と一致するとは限りません。
順位を主張するときは §8 の null 分布を使います。

## 8. null 分布の定義（数式）

**順位を主張する前に、この節の null 分布を測ります。** null 分布がない段階では、
「上位の遺伝子」を介入候補として報告しません（[記述ルール](style-guide.md) A-5）。

### 8-1. 記号と統計量

パネルを 400 細胞とします。遺伝子 `p` を操作したときの遺伝子 `g` の移動度を `e(p, g)` と書きます。

```
e(p, g) = 1 - c(p, g)
c(p, g) = (1 / |C_g|) * Σ_{cell in C_g} cos( x_g^orig , x_g^pert )
```

`c(p, g)` は、遺伝子 `g` を持つ細胞の集合 `C_g` におけるコサイン類似度の平均です。
`x_g^orig` と `x_g^pert` は、操作の前後での遺伝子 `g` の埋め込みベクトルです。

### 8-2. null 遺伝子の選び方（順位合わせ）

対象 `t` に対し、次を満たす遺伝子を null 遺伝子 `n_i` として 20 個以上選びます。
`r(g)` は、`g` を持つ細胞におけるトークン位置（順位符号化の添字、0 が最も発現の多い遺伝子）の中央値です。

```
| ln r(n) - ln r(t) | <= ln 1.3        順位位置を対象の 1.3 倍以内に合わせる
d(n) >= 0.60                          検出率は 60% 以上
n != t、t の上位 50 位以内、既知のドライバー
```

検出率は対象（100%）と一致しません。この差は §8-4 の回帰で補正します。

### 8-3. p 値と q 値

検定する遺伝子 `g` ごとに、null 標本 `{e(n_1, g), ..., e(n_M, g)}` を作ります（`M` は null 遺伝子の数）。
次の量で対象の移動度を標準化します。

```
mu_g     = (1/M) * Σ_i e(n_i, g)
sigma_g  = sqrt( Σ_i (e(n_i, g) - mu_g)^2 / (M - 1) )
z_t(g)   = ( e(t, g) - e_hat(t, g) ) / sigma_hat_g
p_t(g)   = ( 1 + #{ i : e(n_i, g) >= e(t, g) } ) / ( M + 1 )
```

`p_t(g)` は片側（大きい側）の経験 p 値です。分子に 1 を足すのは、p が 0 にならないようにするためです。
同時に多数の遺伝子を検定するため、p 値を Benjamini–Hochberg 法で q 値（偽発見率）に直します。
**判定は `q < 0.05` とします。** `q >= 0.05` の遺伝子は「偶然の範囲」と「応答なし」を区別できないため、
順位を解釈しません。

### 8-4. 検出率の補正

対象はパネルの 100% の細胞に含まれますが、null 遺伝子の検出率は 60〜96% と幅があります。
検出率が高い遺伝子ほど大きく動くため、そのままでは対象を過大評価します。そこで各遺伝子 `g` について
最小二乗法で次を当てはめ、その当てはめ値と残差を使います。

```
e(n_i, g) = beta_0(g) + beta_1(g) * d_i + eps_i
e_hat(t, g) = beta_0(g) + beta_1(g) * d(t)        d(t) = 1（対象は全細胞に含まれる）
sigma_hat_g = sqrt( Σ_i eps_i^2 / (M - 2) )
```

### 8-5. 全体の要約統計量

実行ごとの要約として、null 遺伝子ごとの最大移動度 `S_i = max_g e(n_i, g)` の分布を使います。
その `(1 - alpha)` 分位点を `T_alpha` とし、対象の最大値が `T_alpha` を超えるかどうかを書きます。
`alpha = 0.05` のとき、`T_0.05` は「無関係な遺伝子を操作しても起きる最大の動き」の 95% 点です。

### 8-6. 実行例（NSCLC の TROP2 と CLDN7）

| 項目 | 値 |
|---|---|
| パネル | 悪性細胞 400 個（対象遺伝子を持つ細胞から無作為抽出） |
| null 遺伝子 | 20 個（順位位置を対象の 1.3 倍以内に一致） |
| モデル | V2-104M、fp32、事前学習のみ |
| 実行単位 | 1 条件あたり 1 回（反復なし） |
| 実装 | `analysis/08_null_select.py`、`analysis/09_null_stats.py`（NSCLC ワークスペース） |

**限界**: 反復が 1 回なので、p 値は実行間のばらつきを含みません。M = 20 のとき、得られる最小の p 値は
`1/21 = 0.048` です。より小さい p 値を主張するには null 遺伝子を増やす必要があります。
