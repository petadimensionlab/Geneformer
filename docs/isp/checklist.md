# ISP 遵守項目（チェックリスト）

> **目的**: 複数のエージェント・複数 PC が同時に ISP を進めているため、**解析・解釈・文献・文書・リポジトリ運用**で守る項目を1枚に集約する。
> 数値基準の詳細は **[合格基準](criteria.md)**、用語は **[用語と手法の定義](glossary.md)** を参照。本書はそれらを前提にした「行動規範」である。

---

## A. 解析を回す前

- [ ] **実行条件を記録に残す** — モデル名 / dtype / `max_ncells` / 状態対 / 分類器チェックポイントのパス。後から追えない結果は無効。
- [ ] **摂動対象細胞数を遺伝子ごとに数える** — 500 未満は [C4](criteria.md) 不合格。除外したことを明記する（TREM2・SPP1・CCL2 などは該当）。
- [ ] **陰性対照を入れる** — ACTB・GAPDH など。動いたら指標そのものを疑う。
- [ ] **出力先は実行ごとに分ける** — 既存結果の再利用は fp32/bf16 比較を無効化する（criteria.md §5-5）。
- [ ] **基準を満たす前に規模を広げない** — 失敗の原因が切り分けられなくなる。

## B. 結果の解釈（言ってよいことの境界）

- [ ] **単一モデルの結果だけで標的候補を報告しない** — モデルを替えると 55 遺伝子中 18 個で符号が反転する（差は計算誤差の約7倍）。
- [ ] **2 モデルの一致を「独立な再現」と呼ばない** — トークン化と rank エンコードを共有しているため、発現量由来の効果は両方で一致する。
- [ ] **発現が乏しい遺伝子の順位を解釈しない** — 検出率・摂動細胞数を必ず併記する。
- [ ] **系統マーカーは標的候補にしない** — CD8A・CD4・CD19 などの削除は細胞の identity を崩す方向に動く。
- [ ] **指標の意味を常に添える** — 測っているのは「WT 状態への近さ」であり「病理の改善」ではない。
- [ ] **文献と食い違う結果も書く** — 隠さず「手法の限界」として記録する（分泌性メディエーターで系統的に食い違う）。

## C. 文献の扱い

- [ ] **PMID は「存在」ではなく「対応」まで検証する** — 主張した遺伝子・内容と、取得した題名・要旨が一致するか。
- [ ] **証拠の層を分ける** — 第1層 = 自分で取得して要旨を読んだ。第2層 = 委託・機械照合のみ。第2層は第1層が沈黙する場合に限定し、その旨を書く。
- [ ] **相反する一次文献は両方引用する** — 「相反（判定不能）」とし、片方を都合よく選ばない。
- [ ] **条件依存の判定は感度まで書く** — 疾患段階（早期/後期）や指標（炎症/アミロイド）で向きが変わるものがある。

## D. レポートの書き方

- [ ] **直近の分析の「狙い」と「考察」をピンポイントで書く** — 経緯・背景の復唱は書かない。
- [ ] **短くする** — 表と図を主役にし、1行で足りる説明は1行で書く。長さは正義ではない。
- [ ] **独自の用語・ラベルには説明を付ける** — 用語表を必ず1つ入れる（「符号反転」「ノイズ床」「C4」など）。
- [ ] **実測値と推定値を区別する** — 推定は「推定」と明記。
- [ ] **英語と日本語の両方を出す** — ファイル名は英語が基本名、日本語は `-jp` を付ける（`REPORT-x.md` / `REPORT-x-jp.md`）。
- [ ] **数値・図・表はスクリプトで再生成できるようにする** — 手作業の転記をしない（`templates/README_templates_ja.md`）。

## E. リポジトリ運用

- [ ] **push 前に `git fetch`** — 複数エージェントが同時に push するため、`--rebase` 前提で進める。
- [ ] **文献照合の成果物はコミットしない** — レポート（PDF/DOCX）・図・文献レコード・派生データは `.gitignore` 済み。ローカル専用とする。
- [ ] **再利用するスクリプトは `templates/template_*.py`** — docstring 冒頭に `TEMPLATE` と、埋め込みの数値・判定が記入例である旨を書く。
- [ ] **置き場所を守る** — 解析は `analysis/`、テンプレートは `templates/`、パッチは `patches/`、文書は `docs/`。
- [ ] **認証情報を残さない** — PAT・トークン・ワンタイムコードをチャットやファイルに書かない。
- [ ] **本体と Mouse は独立に管理する** — `petadimensionlab/Geneformer` と `petadimensionlab/Mouse-Geneformer-MPS` は相互参照を持たせない。
