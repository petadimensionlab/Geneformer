# ISP の評価基準（根拠つき）

> **用語・表記・評価の書き方は [`style-guide.md`](style-guide.md) に従います。**
> 本文書は「何をもって成功とするか」＝基準の一覧と、その根拠だけを扱います。

> **この文書の目的**: 遺伝子削除シミュレーションの結果を「合格か不合格か」と判定する前に、
> **その基準がどこから来たのかを明示する**こと。
> 根拠のない基準を置くと、判定そのものが意味を失います。
>
> 以前の版では「摂動対象 500 細胞以上」（当時の表現。現在は「摂動できる細胞」）「埋め込み空間の分離 15% 以上」と書いていましたが、
> **これらは根拠のない私の目安**でした。本版で訂正します。

## 0. 判定の原則

**基準は 3 種類に分類する。** 混ぜてはいけない。

| 種類 | 意味 | 扱い |
|---|---|---|
| **A. 実測に基づく** | 自データまたは同一リポジトリの実行で測った値から決まる | そのまま基準に使える |
| **B. 参照実行から借用** | 別組織・別条件の実測値を借りる | 条件が違うため**未検証**と明記する |
| **C. 未確立** | 決めるための測定をまだしていない | **判定に使ってはいけない**。確立方法を示す |

## 1. 評価基準

**判定の言葉は「合格・不合格・未検証・判定不能」の 4 語だけを使います**（AG-GB10 が定めた運用ルール）。
未検証はまだ測っていないもの、判定不能は測ったが値が定まらないものを指します。

| # | 観点（何を評価するか） | 基準 | 根拠の種類 | 状態 |
|---|---|---|---|---|
| **E1** | 信号の大きさ | `Shift_to_goal_end` が **無効果の分布（null 分布）の 95 パーセンタイルを超える** | C. 未確立 | **要測定**（null 用の遺伝子を走らせて分布を作る） |
| **E1'** | （参考）符号の安定性 | `Shift` > **2.1e-04** | A. 実測 | 確立済。出所は `docs/quantization/REPORT-316M-ISP-jp.md`（AD_spleen・V2-316M、24 遺伝子×3 時点×100 細胞＝72 行のうち符号が反転したのは 4 行で、**すべて \|Shift\| < 2.1e-04**）。この境界はこの条件で測った値であり、条件を変えたら測り直します |
| **E2** | 順位の作れやすさ | 上位遺伝子と null 分布の分離（効果量） | C. 未確立 | **要測定** |
| **E3** | 指標の妥当性 | 陰性対照（ACTB・GAPDH）が null 分布の範囲に収まる | A. 実測（予定） | **未検証**: 陰性対照を入れた実行がまだ無い。次回の実行で必須 |
| **E4** | 遺伝子ごとの測定可能性 | 摂動できる細胞から求めた**ブートストラップ信頼区間の幅が、値そのものより小さい** | C. 未確立 | **要測定**（各遺伝子の摂動できる細胞から算出）。実測例: GSE174367 では 241 個（TREM2）で値が 0 に潰れ、2,281 個（SORL1）では測れた。AD_spleen の TREM2 は 176 個 |
| **E5** | 状態分離 | 参照実行（AD_spleen）の分離と同等以上 | B. 借用 | **未検証**（組織が異なる）。実測（GSE174367、V2-316M、bf16）: `AD` と `WT` は相対距離 **8.92%**（cos 0.9960）、`MG1` と `MG2` は **17.20%**（cos 0.9853）。分離が 2 倍になると `Shift` の大きさも 2.9 倍になった（SORL1: 1.19e-04 → 3.43e-04） |
| **E6** | 再現性 | 計算精度（bf16 / fp32）を変えても符号が一致 | A. 実測 | 確立済（AD_spleen、24 遺伝子×3 時点×100 細胞: 符号一致 **94.4%**（72 行中 4 行が反転）、上位 20 件は **20/20 一致**、平均 \|Δ\| = **8.3e-05**＝平均 \|Shift\| の 11%） |

### 訂正前 → 訂正後

| 項目 | 訂正前（根拠なし） | 訂正後 |

## 2. 未確立の基準を確立する方法

### 2-1. null 分布を作る（E1・E2・E3 の基礎）

**目的**: 「効果が無い場合にどのくらいの値が出るか」を実測する。

- 対象細胞で**実際に検出される**遺伝子から、生物学的に無関係と考えられる遺伝子を選びます。
  実測では、一般細胞機構（リボソーム、翻訳、シャペロン、解糖、ミトコンドリア、細胞骨格、
  タンパク質分解、膜輸送）に属する遺伝子を使いました。
  **当初案の「神経特異的遺伝子、上皮マーカー、嗅覚受容体」は使えません。**
  ミクログリアで検出されず、削除が成立しないためです（実測: 候補の大半が検出率 20% 未満）。
- 同じ条件で削除シミュレーションを走らせ、`Shift_to_goal_end`の分布を得る
- この分布の 95 パーセンタイルを **E1 の基準**とする
- 陰性対照（ACTB・GAPDH）がこの範囲に収まることを **E3 の判定**とする
- **検出率を記録します。** null 用の遺伝子は対象遺伝子より検出率が低く、摂動できる細胞数が
  少なくなります。比較は細胞数に依存しない判定（信頼区間が 0 を除くか）で行います。

**選んだ個数が規定に届かない場合**（AG-MAC の依頼 1 への対応）: 得られた個数を記録し、
**E1 の判定は「暫定」とします。** 根拠の種類は A ですが、標本数が規定に満たないためです。
実測では GSE174367 で **18 個**、PD アトラスで **15 個**でした。いずれも事前に想定した 20 個を下回っています。

### 2-1-2. 陰性対照が摂動できない場合（AG-MAC の依頼 2 への対応）

**陰性対照も検出率の規則を満たすものを選びます。** 満たさない遺伝子は摂動が成立せず、
対照として機能しません。その場合 **E3 は「未検証」**とし、合格とも不合格とも書きません
（確かめる対象が存在しないため）。

実測では、`ACTB` と `GAPDH` は snRNA-seq で検出率が低く、この規則を満たしません
（GSE174367 の MG: `ACTB` **40.0%**、`GAPDH` **15.0%**。PD アトラス: `ACTB` 18.1%、`GAPDH` 15.8%）。
**GSE174367 の `GAPDH` は 15.0% で規則を満たしていません**（摂動できたのは 412 個）。
したがって Step 1 の E3 は、`ACTB` と null 分布だけで判定します。

**代替の陰性対照の選び方**: 検出率 20% 以上の遺伝子のうち、対象遺伝子と同じ細胞型で
検出されるもの、かつ AD やミクログリアの機能に関与しないものを選びます。
Step 2 と並行して測定する null 用の 18 遺伝子（`results/null_gene_set.csv`）が候補になります。

これにより「いくつ以上なら意味があるか」をデータから決められます。

### 2-2. ブートストラップで測定可能性を決める（E4）

**目的**: 「何細胞あれば値が安定するか」を、恣意的な数字ではなく精度から決める。

- 各遺伝子について、摂動できる細胞を復元抽出し、`Shift`の分布（信頼区間）を求めます。
- 信頼区間の幅が値より大きければ**不合格**（判定不能）、小さければ**合格**と判定します。
- 副産物として「何細胞あれば幅が目標以下になるか」が分かり、遺伝子の採用可否を数値で決められる

### 2-3. 状態分離の水準（E5）

- 参照実行（AD_spleen、316M）の分離を測り、同程度以上であることを条件にする
- 組織が異なるため、そのまま当てはめず**未検証**として扱います。

## 3. 実行前後の手順

- [ ] E5（状態分離）を測定し、参照実行と比較する

## 5. これまでに判明した事実（再掲）

- 前回の実行（摂動できる細胞 1,000 個）では、8 遺伝子すべてが 2.1e-04 を下回り、値の散らばりもほぼゼロだった

### Step 2（`results/isp/step2_mg1_mg2/`、完了）

条件は Step 1 と同じで、**状態対のみ `MG1` → `MG2` に変更**しました。

| 遺伝子 | 摂動できる細胞数 | `Shift` | 95% 信頼区間 | 幅 | 0 を除くか | 幅 < 値か |
|---|---|---|---|---|---|---|
| SORL1 | 2,683 | −3.43e-04 | [−4.33e-04, −2.57e-04] | 1.76e-04 | 除く | **満たす** |
| INPP5D | 2,739 | −1.76e-04 | [−2.94e-04, −6.74e-05] | 2.26e-04 | 除く | 満たさない |
| BIN1 | 1,699 | −1.58e-04 | [−2.63e-04, −4.41e-05] | 2.19e-04 | 除く | 満たさない |

**読み方の注意**: 陰性対照の `ACTB` も 0 を除きます（−4.99e-05、1,335 個）。
**「0 を除く」ことは生物学的な意味の証拠になりません。** 意味があるかを決めるのは null 分布との比較です。

**E1' を満たすのは SORL1 だけです**（3.43e-04 > 2.1e-04）。符号も SORL1・INPP5D・BIN1 が負、CSF1R が正と揃いません。

**状態分離（E5）の算出式**（定義で確認）: 「距離 ÷ 2 つのベクトルの平均ノルム」で、
`||a − b|| ÷ ((||a|| + ||b||) ÷ 2)` です。ライブラリに実装はなく、`glossary.md` の定義のみです。
状態平均埋め込みに適用すると `AD` と `WT` は **8.92%**、`MG1` と `MG2` は **17.20%** になります。

### Step 3（`results/isp/null_mg1_mg2/`、完了）

null 分布用の **18 遺伝子**（一般細胞機構に属し、AD・DAM・炎症のいずれにも該当しないもの）を
`MG1` → `MG2` の同一条件で実行しました。内訳と検出率は `results/null_gene_set.csv` にあります。

| 統計量 | 値 |
|---|---|
| 個数 | 18 |
| 平均 \|`Shift`\| | 6.36e-05 |
| 中央値 | 5.00e-05 |
| 四分位範囲（IQR） | 6.59e-05 |
| 最小 / 最大 | 1.78e-05 / **1.55e-04** |
| 95 パーセンタイル（経験分位） | **1.55e-04** |
| 信頼区間が 0 を除く遺伝子 | **5 / 18 = 27.8%** |

**null 分布は 0 を中心にしていません。** 符号付きの平均は **−2.98e-05**、中央値は −3.57e-05 で、
**18 個のうち 14 個（77.8%）が負**でした。
**したがって「負の `Shift`」は遺伝子の効果の証拠になりません。** 何を削除しても負側に出るためです。

### 3-6. 最終判定（E1・E2・E3）

| 基準 | 観点 | 基準 | 根拠 | 実測 | 判定 |
|---|---|---|---|---|---|
| **E1** | 信号の大きさ | \|`Shift`\| > null の 95 パーセンタイル | A（実測） | 閾値 1.55e-04。SORL1（3.43e-04）・INPP5D（1.76e-04）・BIN1（1.58e-04）が超過、CSF1R（8.47e-05）と PLCG2（8.79e-06）は未満 | **暫定合格（3/5）** — 個数が 18 で規定の 20 に満たないため |
| **E2** | 識別力 | \|`Shift`\| > null の IQR | A（実測） | IQR は 6.59e-05。**7 遺伝子すべてが超過** | **不合格**（識別力なし） |
| **E3** | 指標の妥当性 | 陰性対照が null の範囲に収まる | A（実測） | `ACTB`（4.99e-05）と `GAPDH`（3.42e-05）は null の最大値 1.55e-04 以内 | **合格** |

**E1 の閾値が不安定な点に注意します。** 個数が 18 のとき経験分位の 95 パーセンタイルは**最大値と一致**します。
したがって「合格」は「試験した無関係遺伝子をすべて上回った」ことを意味し、余裕はほとんどありません
（BIN1 は 1.58e-04 対 1.55e-04）。**個数を増やせば閾値は下がり、判定は変わります。**
