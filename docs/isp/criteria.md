# ISP の評価基準（根拠つき）

> **用語・表記・評価の書き方は [記述ルール](style-guide.md) に従います。**
> 本文書は「何をもって成功とするか」＝基準の一覧と、その根拠だけを扱います。
> **実測値はここに書きません。** 実行ごとの測定値は実行の記録に書きます（§5）。

> **この文書の目的**: 結果を評価する前に、**その基準がどこから来たのかを明示する**こと。
> 根拠のない基準を置くと、評価そのものが意味を失います。
>
> 以前の版では「摂動対象 500 細胞以上」「埋め込み空間の分離 15% 以上」のような**出所のない目安**を
> 基準として使っていました。現在は、**実測（A）か、実測にもとづく参照（B）**だけを基準にします。

---

## 0-1. 前提（基準を適用する条件）

**基準は条件に依存します。** 数値を評価するときは、**併記する条件の一覧**（[記述ルール](style-guide.md) §A-6）に従って
実行の条件を書き、**その条件の下で測った基準**と比較します。

**条件が変われば基準を測り直します。** とくに `max_ncells` と状態対は `Shift` の大きさに直接効きます。
**別の条件で測った閾値を、そのまま当てはめてはいけません。**

---

## 0. 判定の原則

- **基準は実行の前に決めます。** 事後に基準を当てはめて判定を出すことはしません。
- **根拠の種類（A 実測 / B 借用 / C 未確立）を必ず添えます。** 判定に使えるのは **A** だけです。
  B は比較には使えても結論の根拠にはせず、C では判定しません（[記述ルール](style-guide.md) §A-2）。
- **合否の語（合格・不合格）は使いません。** 測った値と基準の値を併記します（同 §A-3）。
- **標本数が規定に満たない基準では「暫定」と書きます。** 根拠の種類が A でも、個数が足りなければ暫定です。

## 1. 評価基準（E1〜E6）

**判定の言葉は「未検証」「判定不能」の 2 語だけを使います**（2026-09-25 の変更。合否の語は使いません —
[記述ルール](style-guide.md) §A-3）。未検証はまだ測っていないもの、判定不能は測ったが値が定まらないものを指します。

| # | 観点（何を評価するか） | 基準（満たす条件） | 根拠の種類 | 測り方 |
|---|---|---|---|---|
| **E1** | 信号の大きさ | \|`Shift`\| > **null 分布の 95 パーセンタイル** | A（実測、**条件付き**） | null 分布を測り、閾値を実行ごとに記録します（§2-1） |
| **E1'** | （参考）符号の安定性 | 値が**ノイズ床**（精度を変えても符号が保たれる水準）を上回る | A（実測） | 精度を変えた対照実行で測ります |
| **E2** | 識別力 | 仮説遺伝子と null 遺伝子を**区別できる**（効果量・AUC） | A（実測、**条件付き**） | AUC と順位検定を記録します（§2-1） |
| **E3** | 指標の妥当性 | 陰性対照が **null 分布の範囲内**に収まる | A（実測） | 対照遺伝子の値と検出率を記録します（§2-1-2） |
| **E4** | 遺伝子ごとの測定可能性 | ブートストラップ信頼区間の**幅が値より小さい** | A（実測） | 遺伝子ごとに幅を記録します（§2-2） |
| **E5** | 状態分離 | 参照実行の分離と**同等以上** | B（借用） | 埋め込み空間の相対距離を測ります（§2-3） |
| **E6** | 再現性 | 計算精度を変えても**符号が一致** | A（実測） | 精度を変えた対照実行で測ります |

**この表は基準の定義です。** 実行ごとの測定値と、どの基準を使ったかの記録は**実行の記録**に書きます（§5）。

### 訂正した基準（何を根拠に変えたか）

| 項目 | 訂正前（根拠なし） | 訂正後 |
|---|---|---|
| 信号の大きさ | ノイズ床（特定の値）だけ | 変更なし（実測に基づく）＋ **null 分布の 95 パーセンタイル超え**を主基準に |
| 順位の作れやすさ | **ノイズ床の 2 倍**という目安 | **null 分布との分離**に置き換え（2 倍という数字に根拠が無い） |
| 測定可能性 | **500 細胞以上**という目安 | **ブートストラップ信頼区間**による判定に置き換え |
| 状態分離 | **15% 以上**という目安 | **参照実行との比較**に置き換え（15% の根拠が無い） |
| 指標の妥当性 | 陰性対照がノイズ床未満 | 変更なし（実測に基づく） |
| 再現性 | 符号一致 | 変更なし |

## 2. 未確立の基準を確立する方法

### 2-1. null 分布を作る（E1・E2・E3 の基礎）

**目的**: 「効果が無い場合にどのくらいの値が出るか」を実測する。

- 対象細胞で**実際に検出される**遺伝子から、生物学的に無関係と考えられる遺伝子を選びます。
  一般細胞機構（リボソーム、翻訳、シャペロン、解糖、ミトコンドリア、細胞骨格、
  タンパク質分解、膜輸送）に属する遺伝子が使えます。
  **「神経特異的遺伝子」「上皮マーカー」「嗅覚受容体」は使えません。**
  対象の細胞型で検出されず、削除が成立しないためです。
- 選び方は**順位位置を対象に合わせ、検出率の下限を設けます**（[方法と共通設定](methods.md) §8-2）。
- 同じ条件で削除シミュレーションを走らせ、`Shift_to_goal_end` の分布を得ます。
- この分布の **95 パーセンタイルを E1 の基準**とします。
- 陰性対照（削除しても状態が変わらないはずの遺伝子）が**この範囲に収まること**を E3 の基準とします。
- **検出率を記録します。** null 用の遺伝子は対象遺伝子より検出率が低く、摂動できる細胞数が
  少なくなります。比較は細胞数に依存しない判定（信頼区間が 0 を除くか）で行います。

**選んだ個数が規定に届かない場合**: 得られた個数を記録し、**E1 の判定は「暫定」とします。**
根拠の種類は A ですが、標本数が規定に満たないためです。

### 2-1-2. 陰性対照が摂動できない場合

**陰性対照も検出率の規則を満たすものを選びます。** 満たさない遺伝子は摂動が成立せず、
対照として機能しません。その場合 **E3 は「未検証」**とします（確かめる対象が存在しないため）。

**よく使われる対照遺伝子（系統マーカーなど）は、検出率の下限を満たさないことがあります。**
そのときは、検出率の規則を満たす遺伝子から**代替の陰性対照**を選びます。
条件は、対象遺伝子と同じ細胞型で検出されること、かつ仮説に関与しないことです。

### 2-2. ブートストラップで測定可能性を決める（E4）

**目的**: 「何細胞あれば値が安定するか」を、恣意的な数字ではなく精度から決める。

- 各遺伝子について、摂動できる細胞を復元抽出し、`Shift` の分布（信頼区間）を求めます。
- 信頼区間の幅が値より大きければ**判定不能**（測ったがデータでは決められない）、小さければ
  **基準を満たします**（幅と値を併記して書きます）。
- 副産物として「何細胞あれば幅が目標以下になるか」が分かり、遺伝子の採用可否を数値で決められます。

### 2-3. 状態分離の水準（E5）

- 参照実行の分離を測り、**同程度以上**であることを条件にします。
- 組織やデータが異なる場合は、そのまま当てはめず**未検証**として扱います。

## 3. 実行前後の手順

### 実行前

- [ ] E5（状態分離）を測定し、参照実行と比較する
- [ ] 対象遺伝子それぞれの**摂動できる細胞数**を数える
- [ ] 陰性対照と null 用の遺伝子を遺伝子リストに含める

### 実行後

- [ ] null 分布を作り、E1・E2・E3 を判定する
- [ ] 遺伝子ごとにブートストラップ信頼区間を求め、E4 を判定する
- [ ] **根拠の種類（A/B/C）を添えて**報告する。根拠が A でない基準では「暫定」と明記する

---

## 4. 記録する項目

| 項目 | 内容 |
|---|---|
| 実行条件 | トークン長 / 摂動できる細胞数 / 状態対 / モデル / 数値精度 / 分類器の保存先 |
| `max_ncells` | **摂動できる細胞数の上限**。遺伝子ごとの実測値だけでは、上限で切られているのか実際に少ないのか区別できません |
| 遺伝子ごと | **摂動できる細胞数**、`Shift`、ブートストラップ信頼区間、検出率 |
| 分布 | 平均・中央値・四分位範囲・最小・最大 |
| null 分布 | 使用した遺伝子、95 パーセンタイル値 |
| 基準の適用 | 各観点について、**測った値**と**使った基準の値**、その基準の**根拠の種類（A/B/C）** |

## 5. 実測値の置き場所

**この文書には実測値を書きません。** 基準は条件に依存し、条件が変われば測り直すためです。
実行ごとの測定値・判定・出所は、次の**実行の記録**に書きます。

| 記録 | 内容 |
|---|---|
| [結果のまとめ](records/results.md) | in silico perturbation の実行結果と、基準の根拠になった実測 |
| [PD 多領域アトラス](records/pd_atlas.md) | ヒト多領域アトラスの実行結果（null 比較を含む） |
| [結果のまとめ](records/results.md) ほか各実行の `*_combined.csv` | 生の測定値 |

**基準そのものを変えるときは** [記述ルール](style-guide.md) §D の手順に従い、
変更の理由を[競合の記録](conflicts.md)に残します。
