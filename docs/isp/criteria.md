# ISP の評価基準（根拠つき）

> **用語・表記・評価の書き方は [`style-guide.md`](style-guide.md) に従います。**
> 本文書は「何をもって成功とするか」＝基準の一覧と、その根拠だけを扱います。

> **この文書の目的**: 遺伝子削除シミュレーションの結果を「合格か不合格か」と判定する前に、
> **その基準がどこから来たのかを明示する**こと。
> 根拠のない閾値を置くと、判定そのものが意味を失います。
>
> 以前の版では「摂動対象 500 細胞以上」「埋め込み空間の分離 15% 以上」と書いていましたが、
> **これらは根拠のない私の目安**でした。本版で訂正します。

---

## 0. 判定の原則

**基準は 3 種類に分類する。** 混ぜてはいけない。

| 種類 | 意味 | 扱い |
|---|---|---|
| **A. 実測に基づく** | 自データまたは同一リポジトリの実行で測った値から決まる | そのまま基準に使える |
| **B. 参照実行から借用** | 別組織・別条件の実測値を借りる | 条件が違うため**要確認**と明記する |
| **C. 未確立** | 決めるための測定をまだしていない | **判定に使ってはいけない**。確立方法を示す |

## 2. 未確立の基準を確立する方法

### 2-1. null 分布を作る（E1・E2・E3 の基礎）

**目的**: 「効果が無い場合にどのくらいの値が出るか」を実測する。

- 対象細胞で発現している遺伝子から、**生物学的に無関係と考えられる遺伝子を 20〜30 個**選ぶ
  （例: 神経特異的遺伝子、上皮マーカー、嗅覚受容体など。ミクログリアの機能に関与しないもの）
- 同じ条件で削除シミュレーションを走らせ、`Shift_to_goal_end`の分布を得る
- この分布の 95 パーセンタイルを **E1 の基準**とする
- 陰性対照（ACTB・GAPDH）がこの範囲に収まることを **E3 の判定**とする

これにより「いくつ以上なら意味があるか」をデータから決められる。

### 2-2. ブートストラップで測定可能性を決める（E4）

**目的**: 「何細胞あれば値が安定するか」を、恣意的な数字ではなく精度から決める。

- 各遺伝子について、摂動対象細胞を復元抽出し、`Shift_to_goal_end`の分布（信頼区間）を求める
- 信頼区間の幅が値より大きければ「測定不能」、小さければ「測定可」と判定する
- 副産物として「何細胞あれば幅が目標以下になるか」が分かり、遺伝子の採用可否を数値で決められる

### 2-3. 状態分離の水準（E5）

- 参照実行（AD_spleen、316M）の分離を測り、同程度以上であることを条件にする
- 組織が異なるため、そのまま当てはめず**要確認**として扱う

## 3. 実行前後の手順

### 実行前

- [ ] E5（状態分離）を測定し、参照実行と比較する
- [ ] 対象遺伝子それぞれの**摂動できる細胞数**を数える
- [ ] 陰性対照と **null 遺伝子セット**を遺伝子リストに含める

### 実行後

- [ ] null 分布を作り、E1・E2・E3 を判定する
- [ ] 遺伝子ごとにブートストラップ信頼区間を求め、E4 を判定する
- [ ] **根拠の種類（A/B/C）を添えて**判定を報告する。C の基準で判定した場合は「暫定」と明記する

## 4. 記録する項目

| 項目 | 内容 |
|---|---|
| 実行条件 | トークン長 / 摂動できる細胞数 / 状態対 / モデル / 数値精度 / 分類器の保存先 |
| 遺伝子ごと | **摂動できる細胞数**、`Shift`、ブートストラップ信頼区間 |
| 分布 | 平均・中央値・四分位範囲・最小・最大 |
| null 分布 | 使用した遺伝子、95 パーセンタイル値 |
| 判定 | 各観点の判定と、**その基準の根拠の種類（A/B/C）** |

## 5. これまでに判明した事実（再掲）

- 前回の実行（摂動対象 1,000 個）では、8 遺伝子すべてが 0.00021 を下回り、値の散らばりもほぼゼロだった
- TREM2 は AD 側のミクログリア 2,742 個（ミクログリア全体は 4,126 個）のうち **241 個**にしか発現せず、ABCA7 は 216 個、SPI1 は **0 個**だった（GSE174367。別のデータ AD_spleen では TREM2 は 176 個）
- 状態分離は、発現量では 20.3% あるが、埋め込みベクトルでは **8.27%** に縮まっていた
- 計算精度を変えると値は動くが、符号は保たれる（AD_spleen、24 遺伝子×3 時点×100 細胞: 符号一致 **94.4%**、平均 \|Δ\| = **8.3e-05**＝平均 \|Shift\| の 11%、上位 20 件は 20/20 一致）。
- 以前この節にあった「値が 20〜70% 変動した」は、出所を確認できなかったため削除した
