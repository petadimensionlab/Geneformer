# ISP 記述ルール（用語・表現・根拠）

このページは、ISP の解析を進める人（エージェント、共同研究者）が同じ書き方をするための決まりをまとめたものです。
数値の基準は[評価基準](criteria.md)に、用語の意味は[用語と手法の定義](glossary.md)にあります。
**書き方や表記で迷ったときは、このページが唯一の基準です**（各ページの書き方より、このページのルールを優先します）。

## 0. 適用範囲

このルールは、`docs/isp/` の全ページ、テンプレート集（`templates/`）、レポート（DOCX と PDF）、
およびそれらを生成するスクリプトの日本語と英語の文面に適用します。

## 1. 用語の統一表

同じものを別の言葉で書くと読み手が迷います。左の列の表記を使い、右の列の表記は使いません。
初出の場所では、真ん中の列のように意味を一度だけ添えます。

| 使う表記 | 意味（初出で添える説明） | 使わない表記 |
|---|---|---|
| **ISP** | in silico perturbation の略。計算機上で遺伝子を操作する解析 | in-silico（ハイフン付き） |
| **Shift（Shift_to_goal_end）** | 遺伝子を削除したとき、細胞の状態が goal（例: 健常）へどれだけ近づいたかを表す値 | シフト、シフト量 |
| **削除** | 遺伝子を1つ取り除く操作。この Wiki の基本操作 | KO（データ列名を除く）。実験操作の説明として「ノックアウト」は可 |
| **摂動できる細胞数** | その遺伝子のトークンを持ち、実際に削除の対象になった細胞の数 | 摂動対象細胞数、削除できる細胞数 |
| **検出率** | 対象の細胞のうち、その遺伝子を持っている細胞の割合 | 発現率 |
| **符号が反転する**（名詞は「符号の反転」） | 同じ遺伝子で、2つの条件（モデル、組織、時点）の Shift の正負が食い違うこと | 符号が逆、符号反転 |
| **細胞型** | 単球や T 細胞といった区別。データの列名は `celltype` のまま | 細胞集団、細胞種 |
| **健常（WT）** | 比較の基準になる非疾患側 | 正常、コントロール（本文では使わない） |
| **疾患（AD、PD）** | アルツハイマー病（AD）、パーキンソン病（PD）。初出では日本語名を添える | 病態（文脈が不明確なとき） |
| **モデル（V2-104M、V2-316M）** | Geneformer の事前学習済みモデル。数字はパラメータ数を表す | 104M、316M（初出前の単独使用） |
| **数値精度（fp32、bf16）** | 計算に使う浮動小数点の形式 | dtype だけでの言及 |
| **分類器（CellClassifier）** | 細胞型を判定するために追加学習したモデル | ヘッド、probe |
| **移動度** | 埋め込みベクトルの動きの大きさ。Shift の別名として使わない | — |
| **ノイズ床（2.1e-04）** | 計算誤差だけで符号が反転しうる Shift の大きさ | 閾値、しきい値 |
| **基準（E1〜E6）** | [評価基準](criteria.md)で定義した6つの観点。旧称は C1〜C6 | C1〜C6（2026-09 に改名。古い文書を読むときだけ参照する） |
| **目安** | 実測例の間を取った線。合否には使わない | 基準（目安と基準を混ぜない） |
| **根拠の種類（A、B、C）** | A は自分たちの実測、B は他組織や他データからの借用、C は未確立 | 根拠の明示なし |

## 2. 表現ルール

1. **一文で一つのことを書く。** 接続詞で2つ以上の主張をつながない。
2. **主語と述語を省略しない。** 「〜を記録」ではなく「〜を記録します」と書く。
3. **記号で語句を並べない。** 「A／B／C」や「A・B・C」ではなく、読点でつなぐか、箇条書きを分ける。
4. **略語は初出で意味を添える。** 例: ISP（in silico perturbation、計算機上での遺伝子操作）。
5. **記号だけの要約を書かない。** 情報を詰め込むときは表にする。
6. **同じものは同じ語で呼ぶ。** 本文と表で別名を使わない。
7. **断定と推定を分ける。** 推定には「推定」と書き、根拠を添える。
8. **数値には単位と出所を添える。** 出所が分からない数値は書かない。未測定なら「要測定」と書く。
9. **表には単位を書く。** 表の下に注を1つ置き、読み方と条件を説明する。
10. **ページ間の参照はリンクにする。** 「§2 を参照」だけでは読めないため、リンクと節名を添える。
11. **文体は「です・ます」調で統一する。** 手順の指示は「〜してください」と書く。
12. **見出しは名詞句で短くする。** 節の1行目で、その節が何を述べるかを書く。

## 3. 数値と根拠のルール

- **根拠の種類を必ず添えます。** A は自分たちの実測、B は他組織や他データからの借用、C は未確立です。
- **合否の線に使えるのは A だけです。** C の基準で判定した場合は「暫定」と明記します。
- **「基準」と「目安」を区別します。** 目安は合否に使わず、解釈を控える判断に使います。
- **実測には条件を添えます。** モデル、組織、細胞数、遺伝子数、数値精度を書きます。条件のない数値は引用しません。
- **出所はファイル名か実行名で示します。** 例: `docs/quantization/REPORT-316M-ISP-jp.md`、実行名 `isp-316m-bf16-full`。

## 4. 文書の分担

| 文書 | 書くこと | 書かないこと |
|---|---|---|
| [README](README.md) | 索引と全体の状況 | 個別の数値の詳細 |
| [評価基準](criteria.md) | 基準と目安、根拠の種類、判定の手順 | 実行手順の詳細 |
| [用語と手法の定義](glossary.md) | 用語の意味と使い方 | 表記の可否（このページに書く） |
| 記述ルール（このページ） | 用語の統一表、表現のルール、根拠のルール | 個別の解析結果 |
| [遵守項目](checklist.md) | 実行時の行動規範 | 基準の数値そのもの（評価基準に書く） |
| [レポートの標準構成](report_template.md) | レポートの節立て | 文体のルール（このページに書く） |
| [結果](results.md)、[ad_bm](ad_bm.md)、[ad_liver](ad_liver.md)、[pd](pd.md)、[pd_atlas](pd_atlas.md) | 各実行の結果と解釈 | 基準の再定義 |

## 5. 各ページの骨格

1. **目的**: そのページは何のためにあるかを1段落で書きます。
2. **前提**: 対象データ、モデル、条件（組織、時点、細胞数、数値精度）を書きます。
3. **本文**: 結果、解釈、限界を書きます。
4. **出所**: 数値と引用の出典を書きます。

## 6. レポート（DOCX、PDF）の書き方

- 節立ては[レポートの標準構成](report_template.md)に従います。
- 冒頭の要約は5行以内にまとめ、目的と結論を先に書きます。プロジェクトの経緯は書きません。
- 用語表を必ず付けます。
- 日本語版と英語版を作ります。ファイル名は英語を基本とし、日本語版には「-jp」を付けます。
- 数値、図、表はテンプレートのスクリプトで再生成できる状態にします。

## 8. 言語と数値の表記

### 8-1. 言語

| 対象 | 規則 |
|---|---|
| 本文（説明文） | 日本語です。 |
| コード識別子、ファイル名、ディレクトリ名 | 英語のまま書きます（`Shift_to_goal_end`、`max_ncells`）。日本語に置き換えません。置き換えるとコードと本文が対応しなくなります。 |
| 指標名、関数名、パラメータ名 | 英語のまま書きます。初出で日本語の説明を一度だけ添えます。 |
| コミットメッセージ | 英語で書きます（1 行目に種別と要約、本文に理由）。 |

### 8-2. 数値の表記

| 対象 | 規則 | 例 |
|---|---|---|
| 小さい値（`Shift`、相対距離） | 指数表記で有効数字 3 桁 | `5.21e-05`（`0.0000521` とは書きません） |
| パーセント | 小数 1 桁 | `8.3%` |
| 合否の境界 | 指数表記 | `> 2.1e-04` |
| ファイルパス、コマンド、識別子 | バッククォートで囲みます | `` `docs/isp/criteria.md` `` |
| 細胞数、遺伝子数 | 3 桁ごとに区切ります | `4,126` |

### 8-3. `WT` と `Control` は同じ状態です

データの `Diagnosis` 列の値は `AD` と `Control` ですが、ISP の `goal_state` は `WT` です。
初出で「対照（データ上は `Control`、ISP 上は `WT`）」と一度だけ明記し、以降は文脈で統一します。

## 9. 用語や基準を変えるときの手順

1. まずこのページの統一表を直します（表が唯一の正です）。
2. 次に[評価基準](criteria.md)の識別子（E1〜E6）と、各ページからの参照を直します。
3. 最後にレポートを再生成し、日本語版と英語版の両方を差し替えます。
