# 実行結果のまとめ（In Silico Perturbation）

> Shift の値は有効数字 3 桁の指数表記で書いています（例: +6.60e-03）。割合は小数 1 桁です。

> **このページの読み方（先に読んでください）**
>
> ここに載るのは **各実行で測った `Shift` の値**と、**その実行の中での順位**です。
> **AD の 6 臓器では null 比較を行っていません。** したがって
> **このページの順位から「介入候補」を決めることはできません**（[記述ルール](../style-guide.md) §A-5）。
> 順位を主張できるのは null 比較を行った [PD 多領域アトラス](pd_atlas.md) だけで、
> そこでも **null 遺伝子と区別できませんでした**（AUC 0.454 / 0.498）。
> さらに、同じデータでも **モデルを 104M → 316M に替えると 55 遺伝子のうち 18 個で符号が反転します**（下の追試）。
>
> 各節に書くのは **測った値と、その実行内の順位**までです（順位を主張してよい条件は [記述ルール](../style-guide.md) §A-5）。

> 各実験の `Shift_to_goal_end` 上位（正 = 疾患細胞が WT に近づく方向に動いた）を並べます。

## GSE174367（前頭前皮質ミクログリア）の ISP

対象は GSE174367 の前頭前皮質 snRNA-seq、ミクログリア、Geneformer V2-316M です。
段階を 2 つに分けて実行しています（AG-GH の実測）。

| 段階 | 遺伝子 | 実測（`Shift`） | 実測と基準の比較 |
|---|---|---|---|
| Step 1（`AD` → `WT`） | 7 | 最大 1.96e-04（INPP5D）。7 遺伝子すべて \|`Shift`\| < 2.1e-04 | 符号の安定性の基準 2.1e-04 を**下回ります** → **符号が安定する水準に達していません**。対照 `ACTB` は −1.87e-05 で**対象と区別できません**。**この段階の null 分布は測っていません**（null は Step 2 の条件で測ったため、その閾値をそのまま当てることはできません） |
| Step 2（`MG1` → `MG2`） | 7 | SORL1 **−3.43e-04**（Step 1 の 2.9 倍）、INPP5D −1.76e-04、BIN1 −1.58e-04 | **同じ条件で測った** null 分布（18 遺伝子）の 95 パーセンタイル = 1.55e-04 を **3 / 5 が超過**（SORL1・INPP5D・BIN1）。ただし **null との順位の区別はつきません**（E2） |

**この系は、AD の 6 臓器と違って null 分布を測っています**（[評価基準](../criteria.md) §3）。それでも
**仮説遺伝子と null 遺伝子の順位は区別できませんでした。** 値と解釈の詳細は [評価基準](../criteria.md) §2〜§3 にあります。

### 基準の根拠になった実測（判明した事実）

- 前回の実行（摂動できる細胞 1,000 個）では、8 遺伝子すべてが 2.1e-04 を下回り、値の散らばりもほぼゼロだった

- 以前この節にあった「値が 20〜70% 変動した」は、出所を確認できなかったため削除した

条件: モデル V2-316M（分類器は細胞型で微調整）、数値精度 bf16、細胞プール MG、

**判定**

| 基準 | 実測と基準の比較 | 根拠の種類 |
|---|---|---|
| E1' | 最大は INPP5D の 1.96e-04 で、基準 2.1e-04 を**下回る**（7 遺伝子すべて基準未満）→ **符号が安定する水準に達していません** | A |
| E3 | 基準は「陰性対照が**対象 5 遺伝子の範囲内**に収まること」。**収まっています**（`ACTB` −1.87e-05、対象の範囲は −1.96e-04〜+7.72e-05）→ **つまり対照と対象を区別できておらず、指標の妥当性が疑われます** | A |
| E4 | 信頼区間の幅（1.14e-04〜2.50e-04）が値（1.41e-05〜1.96e-04）を**上回る** → **判定不能** | C |
| E5 | 状態分離は埋め込みで 8.27%（cos 0.9966）。参照実行と比べるには組織が異なる → **未検証** | B |
| E6 | 前回の実行で符号の反転を観測 → **基準（符号の一致）を満たしません** | A |

**E3 の基準は、対象の範囲内か（この表）と、null の範囲内か（Step 3 の表）で向きが逆です。**
対象の範囲内に収まることは「対照と対象を区別できない」を意味するため**指標の妥当性が疑われ**、
null の範囲内に収まることは「対照が無関係な遺伝子と同じように振る舞う」を意味するため**妥当**です。

E1 と E2 は null 分布の測定後（Step 2 と並行して実行）に判定します。

**読み方の注意**: 陰性対照の `ACTB` も 0 を除きます（−4.99e-05、1,335 個）。
**「0 を除く」ことは生物学的な意味の証拠になりません。** 意味があるかを決めるのは null 分布との比較です。

**E1' を満たすのは SORL1 だけです**（3.43e-04 > 2.1e-04）。符号も SORL1・INPP5D・BIN1 が負、CSF1R が正と揃いません。

`||a − b|| ÷ ((||a|| + ||b||) ÷ 2)` です。ライブラリに実装はなく、`glossary.md` の定義のみです。
状態平均埋め込みに適用すると `AD` と `WT` は **8.92%**、`MG1` と `MG2` は **17.20%** になります。

null 分布用の **18 遺伝子**（一般細胞機構に属し、AD・DAM・炎症のいずれにも該当しないもの）を
`MG1` → `MG2` の同一条件で実行しました。内訳と検出率は `results/null_gene_set.csv` にあります。

| 統計量 | 値 |
|---|---|
| 個数 | 18 |
| 平均 \|`Shift`\| | 6.36e-05 |
| 中央値 | 5.00e-05 |
| 四分位範囲（IQR） | 6.59e-05 |
| 最小 / 最大 | 1.78e-05 / **1.55e-04** |
| 95 パーセンタイル（経験分位） | **1.55e-04** |

**null 分布は 0 を中心にしていません。** 符号付きの平均は **−2.98e-05**、中央値は −3.57e-05 で、
**18 個のうち 14 個（77.8%）が負**でした。
**したがって「負の `Shift`」は遺伝子の効果の証拠になりません。** 何を削除しても負側に出るためです。

#### 3-6. 最終判定（E1・E2・E3）

| 基準 | 観点 | 基準（値） | 根拠 | 実測と基準の比較 |
|---|---|---|---|---|
| **E1** | 信号の大きさ | \|`Shift`\| > null の 95 パーセンタイル = **1.55e-04** | A（実測） | SORL1（3.43e-04）・INPP5D（1.76e-04）・BIN1（1.58e-04）は**基準を超過**、CSF1R（8.47e-05）と PLCG2（8.79e-06）は**未満**（3/5）。null は 18 個で規定の 20 に満たないため**暫定** |
| **E2** | 識別力 | \|`Shift`\| > null の IQR = **6.59e-05** | A（実測） | 7 遺伝子すべてが**基準を超過**。ただし null の 95 パーセンタイル（1.55e-04）と比べると**順位の区別はつきません**（仮説遺伝子と null 遺伝子を区別できない） |
| **E3** | 指標の妥当性 | 陰性対照が **null の範囲**に収まる（null の最大値 **1.55e-04** 以内） | A（実測） | `ACTB`（4.99e-05）と `GAPDH`（3.42e-05）はいずれも**範囲内**で、無関係な遺伝子と同じように振る舞っています |

**E1 の閾値が不安定な点に注意します。** 個数が 18 のとき経験分位の 95 パーセンタイルは**最大値と一致**します。
したがって「基準を超えた」は「試験した無関係遺伝子をすべて上回った」ことを意味し、余裕はほとんどありません
（BIN1 は 1.58e-04 対 1.55e-04）。**個数を増やせば閾値は下がり、判定は変わります。**

## 制限事項

- **AD の 6 臓器では null 比較を実施していません。** これが**遺伝子名を介入候補として報告できない最大の理由**です
  （[PD 多領域アトラス](pd_atlas.md) では実施済み。結果はそちらに記載しています）
- **モデルを替えると順位も符号も動きます。** 104M → 316M で 55 遺伝子のうち 18 個が符号反転（脾臓の追試）
- `Shift_to_goal_end` はコサイン類似度の差です。p 値は **null 比較を行った実行でのみ**算出できます（[方法と共通設定](../methods.md) §8）
- `max_ncells=200-300` のスクリーニングです。上位候補を分離するにはより多くの細胞で再実行が必要です
- 5xFAD（家族性 AD）/ PFF（散発性 PD）モデル由来です。ヒト散発性疾患への一般化には注意してください
