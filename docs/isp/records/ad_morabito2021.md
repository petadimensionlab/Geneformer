## 2. Abstract（要旨）

- **晩期 AD の 191,890 核**を、**同じ生物学的サンプルから**クロマチンアクセシビリティ（snATAC-seq）と
  遺伝子発現（snRNA-seq）の両方で測ったマルチオミクス単一核研究。
- 細胞型特異的な**疾患有関連候補シス制御エレメント（cCRE）とその候補標的遺伝子**を同定した。
  その中には **APOE と CLU にリンクするオリゴデンドロサイトの制御モジュール**が含まれる。
- **AD の GWAS リスク座位**の一部について、細胞型ごとのシス制御関係を記述した。
- グリアの**トラジェクトリ解析**から、**SREBF1** などの疾患有関連転写因子とその制御標的を同定した。
- **scWGCNA**（単一核コンセンサス重み付き共発現ネットワーク解析）を新規に導入し、
  スパースな単一細胞データに頑健な共発現ネットワーク解析を行った。

## 3. Introduction（背景と目的）

- 脳は不均一な細胞集団からなるが、**疾患病脳の細胞集団の理解は限られている**。
- AD は大規模な神経細胞死とグリオーシスを伴うが、**どの神経細胞・グリア細胞集団が病態生理に関与するかは不明**。
- 既存の snRNA-seq 研究は細胞型特異的な転写変化を示したが、**その疾患有関連サブタイプを制御する因子は未定義**だった。
- AD の GWAS は、**共通変異による遺伝的リスクの相当部分が遠位制御エレメントに分配される**ことを示す。
  それらはしばしば疾患関連組織の細胞型特異的領域である。
- 既存の試み（バルク組織 RNA-seq と ATAC-seq の交差）は、**細胞型の不均一性により解像度が著しく制限**される。
- **GWAS ヒットを細胞型に結びつけるには、遠位制御エレメントと標的遺伝子を結ぶ地図が前提**となる。
- 単一細胞クロマチンアクセシビリティ（snATAC-seq）は、**疾患組織ではほとんど使われていなかった**
  （健常脳での報告は 2 件のみ）。
- **目的**: 同じ AD 死後脳サンプルで snATAC-seq と snRNA-seq を行い、
  **エピゲノムとトランスクリプトームの両水準で AD 関連の遺伝子制御プログラムを定義する**。

## 4. Results

### 4-1. ヒト前頭前皮質のマルチオミクス解析

- **設計**: 前頭前皮質（PFC）の死後脳から核を単離。**同一剖検のアリコートを両アッセイに使う**ことで、
  手法間の細胞型組成のずれを最小化した。
  - snATAC-seq: 晩期 AD **n = 12**、対照 **n = 8**
  - snRNA-seq: 晩期 AD **n = 11**、対照 **n = 7**
  - 年齢 **74〜90 歳以上**、年齢を一致させた認知健常対照。晩期 AD は **Braak と plaque の両ステージング**で定義。
- **品質管理後**: snATAC-seq **130,418 核**、snRNA-seq **61,472 核**。
- **バッチ補正**: snATAC-seq は MNN（潜在意味索引付けした後）、snRNA-seq は iNMF。
- **UMAP + Leiden クラスタリング**: snATAC-seq **35 クラスタ**、snRNA-seq **34 クラスタ**。
- **主要細胞型（snATAC-seq）**: 興奮性神経細胞 24,076（EX.a–e）、抑制性神経細胞 9,644（INH.a–d）、
  アストロサイト 15,399（ASC.a–f）、ミクログリア 12,232（MG.a–e）、
  **オリゴデンドロサイト 62,253（ODC.a–m）**、OPC 4,869（OPC.a）。
- **主要細胞型（snRNA-seq）**: 興奮性 6,369（EX1–5）、抑制性 5,962（INH1–4）、
  アストロサイト 4,756（ASC1–4）、**ミクログリア 4,126（MG1–3）**、
  **オリゴデンドロサイト 37,052（ODC1–13）**、OPC 2,740（OPC1–2）。
- **両アッセイでオリゴデンドロサイトが最多**だった。
- マーカー遺伝子の例: **LINC00507**（EX1 = L2-3 興奮性）、**SV2C**（INH4 = L3 介在）、
  **CX3CR1**（**MG2 = ホメオスタティックなミクログリア**）。
- **chromVAR** で TF モチーフの変動を核ごとに計算し、診断との関連で細胞型ごとに検討。
  アストロサイト・興奮性神経細胞・ミクログリアで、疾患に伴い富化が増えるモチーフを複数同定。
- **TF フットプリント解析**では、オリゴデンドロサイトの **SOX9** フットプリントを強調。
- **統合解析**: Seurat の CCA + MNN アンカーで両モダリティを統合。**94% の細胞で予測スコア ≥ 0.5** となり、
  2 つのデータモダリティ間の高い対応を確認した。

### 4-2. AD における細胞不均一性のマルチオミクス的特徴づけ

- 神経細胞・グリアの**複数のサブポピュレーション**を発見し、既知のマーカー遺伝子で注釈した。
- **疾患によるクラスタ比率の変化**（25 回のブートストラップ、両側 Wilcoxon 順位和検定、BH 補正）:

| クラスタ | 特徴 | 方向 | FDR |
|---|---|---|---|
| ASC3 | GFAP high / CHI3L+ | **増加** | 8.63 × 10⁻⁵ |
| ASC4 | GFAP low / WIF1+ / ADAMTS17+ | **減少** | 4.68 × 10⁻⁷ |
| MG.a | 活性化ミクログリア | 増加 | 9.82 × 10⁻⁷ |
| MG.b | 活性化ミクログリア | 増加 | 8.88 × 10⁻¹⁰ |
| **MG1** | **SPP1 high / CD163+** | **増加** | 6.32 × 10⁻⁷ |
| ODC13 | immune oligodendrocyte | 増加 | 1.62 × 10⁻⁴ |

- **MG.a と MG.b はどちらも snRNA-seq の MG1（SPP1 high / CD163+）に対応**し、MG1 自体も疾患で増加していた。
- **ASC3/ASC4 の変化は、5XFAD マウスの snRNA-seq 研究の報告と一致**する。
- 各クラスタで**差次的アクセシブル領域と DEG** を同定し、GO 富化が高いクラスタ特異性を示すことを確認。
- 例: **NEAT1 がアストロサイトとオリゴデンドロサイトで上昇**し、in situ ハイブリダイゼーションで確認した
  （内嗅皮質の先行報告と一致）。

### 4-3. 晩期 AD における細胞型特異的な cis 遺伝子制御

- 細胞型ごとに、**晩期 AD と対照で別々に cis 共アクセシビリティネットワーク（CCAN）**を構築。
- 一方のピークが**プロモーター**にある共アクセシブルなピーク対に注目し、**cCRE と候補標的遺伝子**の組を得た。
- さらに、**cCRE のアクセシビリティと候補標的遺伝子の発現を相関**させ、
  共アクセシビリティだけでは得られない制御関係の証拠を強めた。
- **NMF で gene-linked cCRE（gl-cCRE）をクラスタリング**し、機能モジュールとしてまとめた。
- **合計 56,552 gl-cCRE、11,440 cCRE リンク遺伝子**。1 遺伝子あたり**中央値 4 個の cCRE**がリンク。
- 細胞型をまたいで共有される遺伝子と、細胞型特異的な遺伝子の両方を確認。
  **共有される標的遺伝子の一部は、細胞型ごとに異なる cCRE で制御されていた。**
- cCRE リンク遺伝子の集合は、細胞型マーカー DEG や AD で上昇する遺伝子と有意に重なった。
- **gl-cCRE の 58.35% がイントロン領域**にマップされた。
- NMF 係数行列から、各モジュールがどのクラスタ／細胞型に対応するかを同定し、
  対照特異的モジュールと晩期 AD 特異的モジュールを注釈した。

### 4-4. 晩期 AD における細胞型特異的転写因子

- **ミクログリアの SPI1（別名 PU.1）** と **オリゴデンドロサイトの NRF1** を検討。
- **SPI1 の標的は MG1 でのみ有意に発現低下**していた。
  → 論文は「**SPI1 は晩期 AD で転写抑制因子として働く**」と結論づけている。
- **NRF1 は一部のオリゴデンドロサイトクラスタで調節異常**。NRF1 はミトコンドリア機能と関連づけられており、
  その調節異常によるミトコンドリア機能障害が、**髄鞘化の障害を通じて晩期 AD の神経機能障害に寄与**しうると議論。
- 神経細胞集団の TF 解析と、**アストロサイトの FOSL2** は Extended Data に示されている。
- **細胞型特異的 TF 制御ネットワーク**を構築（ミクログリアは SPI1、オリゴデンドロサイトは NRF1）。
  ネットワークには **AD の DEG と既知の AD GWAS 座位の遺伝子**が複数含まれた。

### 4-5. 疾患病態グリアの統合トラジェクトリ解析

- **方法**: 統合データに対して Monocle3 で擬似時間トラジェクトリを構築し、
  **RVAE（再帰変分オートエンコーダ）**で遺伝子発現とクロマチンアクセシビリティの動態をモデル化。
  2 次元潜在表現と脱ノイズ化された再構成が得られる。トラジェクトリに沿って差次的に発現する遺伝子（t-DEG）を
  各細胞型で同定し、それを特徴量として RVAE を学習させた。

**オリゴデンドロサイト（SREBF1）**

- snATAC **58,221 核** + snRNA **36,773 核**。**トラジェクトリに沿って晩期 AD 核の比率が増加**
  （Pearson R = 0.32、P = 0.022）。
- 遺伝子シグネチャ: 成熟 ODC は終端で増加、髄鞘形成 ODC（MF-ODC）は減少、
  新生 ODC（NF-ODC）は全行程で減少 →
  **このトラジェクトリはオリゴデンドロサイトの成熟を再現している**と解釈。
- gl-cCRE **9,231**、t-DEG **1,563** を RVAE でモデル化。
- **NRF1 モチーフ変動は晩期 AD で上昇**（Bonferroni 補正 P = 5.13 × 10⁻²⁰）。
- **SREBF1 モチーフ変動は疾患で低下**（Bonferroni 補正 P = 2.67 × 10⁻¹⁹¹）。
- トラジェクトリとの相関: **NRF1 は終端で標的遺伝子と負に相関**、
  **SREBF1 は始点と終点の両方で正に相関** → **SREBF1 は活性化因子として働く**。

**ミクログリア（DAM、SPI1・ETV5）**

- snATAC **10,768 核** + snRNA **4,119 核**。**トラジェクトリに沿って晩期 AD 核が有意に増加**
  （Pearson R = 0.53、P = 6.9 × 10⁻⁵）。
- **DAM シグネチャ**（5XFAD マウスの単一細胞研究で提唱され、AD ゲノミクスで議論が多い）を検討:
  ホメオスタティックシグネチャは**減少**、ステージ 1 DAM は**増加**、
  **ステージ 2（TREM2 依存性）DAM は全体として明らかに枯渇**していた。
  → このトラジェクトリは**ホメオスタティックから疾患有関連状態への転換**を記述していると解釈。
- gl-cCRE **9,163**、t-DEG **2,138** を RVAE でモデル化。
- ETS ファミリーの **SPI1**（P = 1.19 × 10⁻²⁰）と **ETV5**（P = 6.68 × 10⁻¹⁹）のモチーフ変動が晩期 AD で上昇。
  **SPI1 のモチーフトラジェクトリは終端で遺伝子と負に相関** →
  「SPI1 が抑制因子として働く」という §4-4 の結論を支持。

**アストロサイト（DAA、CTCF・FOSL2）**

- snATAC **12,112 核** + snRNA **4,704 核**。**トラジェクトリに沿って晩期 AD 核が有意に増加**
  （Pearson R = 0.57、P = 1.9 × 10⁻⁵）。
- **DAA シグネチャ**（5XFAD 海馬の snRNA-seq で報告された、加齢野生型の GFAP-high とは区別される
  AD 特異的 GFAP-high アストロサイト）を検討 →
  **GFAP-low から GFAP-high／DAA 様状態への傾向**をたどると解釈。
- gl-cCRE **12,487**、t-DEG **1,797** を RVAE でモデル化。
- **CTCF** モチーフ変動は晩期 AD で**低下**（P = 6.45 × 10⁻¹⁷）し、
  DAA／GFAP-high シグネチャと**逆相関**、GFAP-low 期の t-DEG とは**正相関**。
- **FOSL2** モチーフ変動は晩期 AD で**上昇**（P = 5.65 × 10⁻⁹⁹）し、
  GFAP-high／DAA シグネチャと終端の遺伝子に**正相関**。
  → 「**FOSL2 は DAA シグネチャの活性化因子、CTCF はよりホメオスタティックな状態を促す**」と解釈。

### 4-6. AD 遺伝的リスク座位における細胞型特異的な cis 制御

- snATAC-seq クラスタで **LDSC（連鎖不平衡スコア回帰）**を AD および関連形質の GWAS 要約統計に対して実施。
- **ミクログリアクラスタ MG.b と MG.c** は **Kunkle ら**の AD GWAS SNP で有意に富化（FDR < 0.05）。
- **5 つすべてのミクログリアクラスタ**が **Jansen ら**の SNP で有意に富化
  （MG.a・MG.e は FDR < 0.005、MG.b・MG.c・MG.d は FDR < 0.0005）。
- **gchromVAR** で、Jansen らの fine-mapping 済み AD 関連多型の富化をミクログリア擬似時間に沿って計算:
  **遠位ピークでは有意に増加**（P = 0.0048）、**遺伝子近位ピークでは有意に減少**（P = 0.0053）。
  → **AD 関連 SNP は DAM の遠位エンハンサーに位置する**ことを示す。
- 共アクセシビリティ地図と GWAS 統計をゲノム軸に重ね、
  **BIN1、ADAM10、APOE、SLC24A4** などの GWAS 遺伝子で、原因変異により撹乱される可能性のある
  シス制御関係を明らかにした。
- **APOE 座位**（AD 遺伝率の主要決定因子を含む最も研究された座位）は、
  **ミクログリアとアストロサイトで疾患時にシス制御クロマチンネットワークが変化**していた。

### 4-7. scWGCNA による単一細胞共発現ネットワーク

- **課題**: WGCNA はバルク発現データ向けに設計されており、スパースでノイズの多い単一細胞データには
  ほとんど使われてこなかった。
- **方法**: **メタセル**（k 近傍 **50 細胞**の平均発現）で単一細胞のスパース性を回避。
  Mathys らの公表 snRNA-seq を iNMF で自データと統合。
  さらに**新規にバルク RNA-seq を実施**（早期 AD・晩期 AD・病理対照）し、ROSMAP のバルク RNA-seq も加えた。
  **consensus WGCNA** で統合 snRNA-seq と 2 コホートのバルク RNA-seq から共発現ネットワークを同時構築
  → これを **scWGCNA** と名付けた。
- **オリゴデンドロサイト**で 4 つのモジュール（**OM1、OM2、OM4、OM5**）が AD 診断と有意に相関:
  - **OM1**: ハブ遺伝子がリボソームサブユニット（**RPS15A、RPL30、RPL23A**）、
    タンパク質合成・ソーティングの GO 用語に富化。**AD で低下**。
  - **OM2**: **MAG、CNP、PLP1**（髄鞘化）。**AD で低下**。
- オリゴデンドロサイトの**3 モジュールが SREBF1 の標的に有意に富化**。
- バルク RNA-seq・ハイスループットプロテオミクス・**ENCODE の SREBF1 ChIP-seq** を組み合わせ、
  **SREBF1 標的遺伝子のタンパク質間相互作用（PPI）ネットワーク**を定義。
- **SREBF1 標的のモジュール固有発現は、早期 AD と晩期 AD の両方でタンパク質・RNA の両水準で低下**。
  snATAC-seq の SREBF1 モチーフ変動低下とも一致。
- **RNAscope（in situ ハイブリダイゼーション）と免疫組織化学で SREBF1 の低下を検証**し、
  SREBF1 の標的である **ACSL4 の発現低下**も確認した。

## 5. Discussion（考察）

- 統合マルチオミクス解析は、**疾患病因の根底にある細胞不均一性の連続体**への独自の視点を与える。
  複雑な疾患の因果機構の特定には、**エピゲノムとトランスクリプトーム両水準での
  細胞集団特異的な遺伝子制御系の厳密な理解**が要る。
- 単一細胞クロマチンアクセシビリティは**本質的にスパース**で扱いが難しい。
  本論文は**同一サンプルからの 2 モダリティ統合**と、疑似バルクアクセシビリティプロファイリング・
  共アクセシビリティ解析といった**集約手法**でこれを回避した。
- **主要な貢献は、細胞型特異的な gl-cCRE と、そこに結合しうる TF を同定したこと**。
  エピゲノムデータだけでも cCRE は同定できるが、**単一核トランスクリプトームとの統合**により、
  候補標的遺伝子の発現と cCRE のアクセシビリティを結びつけて裏づけている。
  **これまでの AD 研究は、細胞型・サブポピュレーション水準でのシス遺伝子制御を検討していなかった。**
- シス・トランス両方の制御異常を提示し、
  **オリゴデンドロサイトの NRF1、アストロサイトの FOSL2** など、今後の検討対象を示した。
- GWAS で示唆される遺伝性リスク遺伝子について、
  **AD と対照の細胞集団間でシス制御ネットワークを比較**し、**疾患に固有の相互作用**を同定した。
  本論文は **AD コミュニティのためのリソース**として位置づけられている。
- オリゴデンドロサイトのトラジェクトリは**成熟を再現**し、
  **SREBF1 のモチーフ変動低下・遺伝子発現低下**、トラジェクトリ全体での標的との正相関（＝活性化因子）を示した。
- **scWGCNA** はメタセルによりスパース性に対処し、ROSMAP を加えた**メタ解析**でロバスト性を確保した。
  3 つのオリゴデンドロサイトモジュールが SREBF1 標的に富化し、
  遺伝子・タンパク質水準で低下していたことから、
  **SREBF1 は AD 治療標的の候補として優先的に追跡すべき遺伝子**と結論。
- **限界**: 孤発性 AD の原因機構は依然不明。AD および神経変性一般について、
  **遺伝子発現とエピゲノミクスの複雑さを空間的に解像する追加研究が必要**。
- **ポータル**（`swaruplab.bio.uci.edu/singlenucleiAD`）により、結果を誰でも探索できる。

## 6. Methods（方法）

| 節 | 要点 |
|---|---|
| Human samples | PFC サンプルは **UCI MIND ADRC** 組織リポジトリ（UCI IRB）と **ROSMAP**（Rush University Medical Center IRB）から。乾氷上で解剖・ホモジナイズし、**snRNA-seq と snATAC-seq 用にアリコート**。AD **男性 6・女性 6**、対照 **男性 5・女性 3**、全員 **74〜90 歳以上**。ROSMAP RNA-seq は Synapse `syn3219045`。 |
| Bulk RNA-seq | PFC から total RNA を抽出。**Takara SMARTer Stranded Total RNA Sample Prep**。-80°C 保存。NovaSeq S4 で **100 bp ペアエンド**、2 レーンに 96 と 95 サンプルをマルチプレックス。 |
| Single-nucleus RNA-seq | 凍結 PFC **約 50 mg**、Nuclei EZ Lysis、70 µm フィルタ、**DAPI で FACS**、**10x Chromium Single Cell 3' v3**。**NovaSeq 6000 S4**（New York Genome Center）。 |
| Single-nucleus ATAC-seq | 凍結 PFC 約 50 mg。**ショ糖勾配**で細胞残渣を除去（13,000 g、45 分、4°C）、**10x Chromium Single Cell ATAC**。NovaSeq 6000 S4（UCI Genomics core）。 |
| RNAscope（FISH） | 凍結切片 20 µm。プローブは **NEAT1、PLP1、CNP、SREBF1、ACSL4、MOG、AQP4**。**QuPath** で 4 領域を解析、訓練済み分類器で核を同定（ACSL4/MOG 二重染色のみ背景が高く手動）。**線形混合効果モデル**（ランダム効果: 年齢・性別、固定効果: 同一人物の複数領域）。 |
| Immunofluorescence | 40 µm 切片。抗体は **6E10、Iba-1、MAP2、GFAP、PDGFRA、Olig2**。**IMARIS** でプラーク体積を解析。同じく線形混合効果モデル。 |
| Annotation of major cell types | 正準マーカー遺伝子の手動確認。**Signac の CoveragePlot**、**Seurat**。snRNA-seq の注釈は **Mathys らのデータセットとの統合で検証**。 |
| 統合解析 | **Seurat の統合フレームワーク**。CCA で共有次元削減 → MNN でアンカー同定。**ラベル転送で 94% の細胞が予測スコア ≥ 0.5**。アンカーで snATAC に発現を補完し、PCA 30 次元、MNN でバッチ補正、UMAP、Leiden。 |
| 細胞型特異的な次元削減・クラスタ解析 | 主要細胞型ごとにサブセットして UMAP 再埋め込み + Leiden。**100 細胞未満のクラスタは除外**。**ArchR の addReproduciblePeakSet + MACS2** でピークを同定。 |
| クラスタ比率の解析 | **25 回のブートストラップ**、各回で全体の **20% をサンプリング**し、AD／対照の比率を算出。**両側 Wilcoxon 順位和検定 + BH 補正**。 |
| TF モチーフ解析 | **JASPAR 2018 の 452 TF** について、**Signac 経由の chromVAR**（v1.12.0）でモチーフ富化を計算。 |
| 追加の解析 | トランスクリプトームとクロマチンの独立・共同解析（Supplementary Note）、scWGCNA、gchromVAR、LDSC。 |

## 8. 私たちの ISP 解析との接続点

1. **MG1 と MG2 の定義はこの論文に由来します。**
   本論文では **MG2 がホメオスタティック**（マーカー `CX3CR1`）、
   **MG1 が活性化**（`SPP1` high / `CD163+`、晩期 AD で有意に増加、FDR 6.32 × 10⁻⁷）です。
   私たちの Step 2 の状態対 **`MG1` → `MG2`** は、**この論文のホメオスタティック⇄活性化の軸**をそのまま使っています。
2. **`max_ncells=4126` の数字の出所が説明できます。**
   [criteria.md](../criteria.md) §0-1 は `max_ncells=4126` を指定していますが、
   これは**この論文の snRNA-seq ミクログリア核数 4,126** と一致します。
   Step 1/Step 2 の摂動対象がこの論文の MG プールそのものであることの傍証です。
3. **この論文は仮説の供給源になります。** 私たちの Step 2 で
   `SORL1` の `Shift` が `MG1` → `MG2` の分離拡大に伴い **2.9 倍**になった事実は、
   この論文の **MG1（活性化、SPP1/CD163）↔ MG2（ホメオスタティック、CX3CR1）** という
   状態軸の上で読むべきものです。
4. **反証可能な仮説の候補**（論文側の主張から直接導かれるもの）:
   - **SPI1 は晩期 AD の MG1 で抑制因子として働く**（§4-4・§4-5）。
     → MG1 で **SPI1 標的を削除すると `Shift` が正に出る**（健常側へ戻る）はず。
     これが**負に出る／出ない**なら、この論文の主張は ISP では支持されない。
   - **TREM2 依存性（ステージ 2）DAM は晩期 AD で枯渇**している（§4-5）。
     → MG1→MG2 の軸で **TREM2 を削除しても大きな `Shift` は出ない**はず。
     E4（測定可能性）の制約もあり、`TREM2` は**摂動できる細胞が 241 個**と少ないため、
     この検証は**ブートストラップ信頼区間**と併記が必要です。
   - **SREBF1 はオリゴデンドロサイトの活性化因子で、晩期 AD で低下**（§4-5・§4-7）。
     → ただし**私たちのプールは MG のみ**で、オリゴデンドロサイトを対象にしていないため、
     **この仮説は現状の ISP では検証できません**（対象外であることを明記します）。
