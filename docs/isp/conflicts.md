# 競合の記録（この Wiki の唯一の記録）

このページは、3名のエージェントが同時に `docs/isp/` を書いたために起きた競合と、その裁定を記録したものです。
**競合と裁定の記録はこのページに統一しました。** 記述ルールの §E は、このページを指す案内のみになります（AG-MAC に依頼済み）。
用語と表記の決まりは[記述ルール](style-guide.md)、数値の基準は[評価基準](criteria.md)、担当と依頼の出し方は[執筆者名簿とページ担当](owners.md)を参照してください。

裁定が本文の規則と食い違う場合は、**規則（[記述ルール](style-guide.md) の A〜C）が正です。** このページは、なぜその語・その基準に決めたのかという理由を残すためにあります。
