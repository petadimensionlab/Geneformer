# 競合の記録（3名のエージェントが同じ Wiki を書いた結果）

このページは、3名のエージェントが同時に `docs/isp/` を書いたために起きた競合を記録したものです。
同じ競合を繰り返さないために、何がぶつかり、どう解消したかを残します。
裁定（どの語・どの基準に決めたか）の一覧は[記述ルール](style-guide.md) §E にあります。このページは**経緯**の記録です。
用語と表記の決まりは[記述ルール](style-guide.md)、数値の基準は[評価基準](criteria.md)を参照してください。

> **このページは [記述ルール](style-guide.md) の §9「競合・重複の記録」と内容が重複しています。**
> こちらは**経緯**の記録（git が止まった競合、push が拒否された回数、記録時点で残っている不一致）で、
> あちらは**裁定だけの一覧**です。**規則そのものが食い違ったら [記述ルール](style-guide.md) §9 が正です。**
> 重複を承知で 2 か所に置いているのは、経緯を知らないと判断を誤るためです。

## 1. git が止まった競合

ファイルの同じ場所を2人が同時に書き換えたため、取り込み（rebase）が止まった事例です。

| # | 日時 | ファイル | ぶつかった内容 | 解消のしかた |
|---|---|---|---|---|
| 1 | 09/16 13:09 | `docs/isp/criteria.md` | 私が「根拠のない数値を合否基準にしない」訂正を出し、別のエージェントが同じ趣旨の訂正を同時に出した。第1章の全文（14〜117行）が衝突した | 相手の版（E1〜E6、根拠の種類 A・B・C、null 分布とブートストラップによる定義）を土台に採用し、私の実測値だけを追加した。出所を確認できなかった「20〜70% 変動」は削除した |
| 2 | 09/16 13:16 | `docs/isp/style-guide.md` | 私が表記と判定語彙の規則を追加し、別のエージェントが同じ規則を同じファイルに統合した。表現ルールの末尾（36〜42行）が衝突した | 相手の版を採用した。相手の版は同等の規則をすでに取り込んでいたため、私の重複分は破棄した |

## 3. git の競合にはならなかったが、内容が重複・矛盾していた事例

同じ内容を2人が別の書き方で持っていたため、読み手が迷う状態になっていた事例です。
いずれも解消済みです。

| # | ぶつかっていた内容 | 統一した形 |
|---|---|---|
| 1 | ルール文書が3つ併存していた。`style-guide.md`（私）、`writing_standard.md`（コミットメッセージで宣言されたが、ファイルは未コミット）、`CONVENTIONS.md`（別のエージェントが122行で追加し、「この文書が唯一の基準」と宣言） | `style-guide.md` に統合し、残り2つは内容を取り込んで削除した |
| 2 | 用語の統一表が `glossary.md` 第13章と `style-guide.md` 第1章の2か所にあった | 表は `style-guide.md` の1か所に置き、`glossary.md` は案内だけにした |
| 3 | 評価基準の記号が C1〜C6（旧）と E1〜E6（新）の2種類併存していた | E1〜E6 に統一し、旧称は `style-guide.md` に注記として残した |
| 4 | 根拠の書けない数値（IQR 4.2e-04、細胞数500、状態分離15%）が合否の基準に使われていた | すべて「目安」に降格した。合否には実測に基づく基準（A）だけを使う |
| 5 | TREM2 の摂動できる細胞数が「241個」と「176個」の2通り書かれていた。241個は GSE174367 のミクログリア、176個は AD_spleen の値だった | データごとに分けて書き、どちらの値かを明記した |
| 6 | 「計算精度を変えると値が20〜70%変動する」と書かれていたが、出所を確認できなかった | 実測値（符号一致 94.4%、平均の差 8.3e-05）に置き換え、旧記載を削除したことを明記した |
| 7 | 判定の言葉が「保留」「未達」「未実施」「合格／不合格」とばらばらだった | 「合格、不合格、未検証、判定不能」の4語に統一した |
| 8 | 同じものを「符号が逆」「摂動対象細胞数」「削除できる細胞数」「発現率」「細胞種」「細胞集団」「in-silico」と書いていた | 統一表の表記に置き換えた。図の凡例も同じように直した |
| 9 | レポートの数値が「-0.00055」のような生の小数で、規則の指数表記ではなかった | 「-5.50e-04」の形（有効数字3桁）に統一した |
| 10 | レポートの表1の3行目を「条件を1つだけ変えた比較」と書いていたが、実際にはモデルと数値精度と細胞数の3つが同時に違っていた | 見出しを「変えた条件」に直し、84.9% はモデル差の上限であると注に明記した |
| 11 | 実行前のチェックリストが `criteria.md` と `checklist.md` の2か所にあった | `criteria.md` を正式なリストとし、`checklist.md` は落としやすい3点だけを残した |
| 12 | `report_template.md` の「1. 背景」と、`checklist.md` の「背景の経緯は書かない」が矛盾して見えた | 「背景は数行に留める」と明記し、2つのページを相互にリンクした |
