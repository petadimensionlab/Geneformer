# 用語と手法の定義（ISP / Geneformer）

数値の意味を読み取るための前提です。上から順に積み上げて説明します。
（合格基準は [criteria.md](criteria.md) を参照）

---

## 1. Geneformer

遺伝子の発現パターンを「文章」のように扱うモデル。大量の単一細胞データで、
遺伝子の並びから隠された遺伝子を当てる練習（マスク言語モデル）をさせてあります。
本ワークスペースでは V2-104M と V2-316M を使用。

## 2. トークン化

細胞 1 個を、その細胞で**発現している遺伝子の並び**に変換します。

- 使うのは「発現量の多い順」に並べた遺伝子 ID（Ensembl）の列だけ
- 発現量そのものの数値は使わない（並び順だけが情報）
- 並びの長さは最大 4,096（V2 の上限。データによって中央値は異なる）

この並びを**トークン列**と呼びます。以降のすべての計算はこの並びを入力にします。

## 3. 埋め込み（embedding）

モデルが細胞 1 個を表すために出力する **1,152 次元（316M の場合）の数値の並び**。
似た細胞は近いベクトルになり、違う細胞は離れます。

本ワークスペースでは **[CLS] トークン**（並びの先頭に付く特別なトークン）の出力を使います。
「CLS 埋め込み」と書いたらこれを指します。

- **コサイン類似度**: ベクトルの向きの近さ（1 に近いほど似ている）
- **ユークリッド距離（L2）**: ベクトル間の距離
- **相対距離** = 距離 ÷ 2 つのベクトルの平均ノルム。スケールに依らない比較に使う（0.08 なら 8%）

## 4. 分類器の fine-tune（追加学習）

事前学習済み Geneformer に、**細胞の種類を当てる**タスクを追加で学習させます。

- 分割は**検体単位**（例: `_1` で学習 / `_2` で検証 / `_3` でテスト）。細胞単位で分けると過大評価になる
- 最初の数層は固定し、残りを学習させる（`freeze_layers`）
- 得られた「分類器」は、ISP の埋め込みを計算するために使う
- **長時間の学習はステップ単位チェックポイントを有効にする**（`patches/checkpoints/`）。中断で全損しないため

## 5. in silico perturbation（ISP）

ある遺伝子を**無かったこと**にして（トークン列から削除して）、もう一度埋め込みを計算し直す操作。
実験でのノックアウトを計算機上で行うイメージです。

- 削除は 1 遺伝子ずつ（`combos=0`）。リストでまとめて渡すと「全遺伝子を同時に持つ細胞」条件になり細胞が空になる
- 削除できるのは **その遺伝子のトークンを実際に持っている細胞だけ**（重要）
- 1 回に使う細胞数の上限が **`max_ncells`**。対象細胞数に対して小さすぎると測定にならない
- 状態埋め込みは 1 回計算して全遺伝子で共有する

## 6. start_state と goal_state（状態対）

「どちらからどちらへ動くか」を決める 2 つの状態。

- **start_state**: 動かしたい側（例: 疾患 = `AD`）
- **goal_state**: 近づけたい側（例: 健常 = `WT`）
- **細胞プール**（`filter_data`）: 対象にする細胞型（例: ミクログリア `Microglia`）

「疾患の◯◯細胞から遺伝子を 1 つ消したとき、健常の◯◯細胞にどれだけ近づくか」を測ります。

## 7. Shift_to_goal_end（主指標）

```
Shift_to_goal_end = cos(削除後の埋め込み平均, goal の埋め込み平均)
                  − cos(削除前の埋め込み平均, goal の埋め込み平均)
```

- **正**: 削除で goal に近づいた ＝ その遺伝子を抑えると健常側に戻る（介入ターゲット候補）
- **負**: goal から遠ざかった ＝ 健常状態の維持因子
- **0 に近い**: 削除しても状態がほとんど変わらなかった

## 8. なぜ値がもともと小さいのか

同じ細胞型の中の比較では、細胞同士が元々とても似ています
（例: ミクログリアの AD と対照で cos = 0.9966）。
そのため Shift は 1e-4〜1e-3 の桁にしかなりません。
**大きさではなく、遺伝子間の順位として読む指標**です。

## 9. ノイズ床（2.1e-04）

`docs/quantization/REPORT-316M-ISP-jp.md` の実測によると、
**2.1e-04 を下回る値は fp32↔bf16 で符号が反転します**（順位が安定しない水準）。

参考値（AD_spleen 316M の実測）: 平均 7.5e-04 / 25%点 2.4e-04 / 50%点 4.1e-04 / 75%点 1.2e-03。

## 10. 状態分離（separation）と「圧縮」

「2 つの状態がそもそもどれだけ違うか」の大きさ。

- 発現量（pseudobulk 平均）で見た差
- ISP が実際に使う**埋め込み空間**での差

埋め込みでの差が小さいとき、Shift はノイズに埋もれます。
分類器を「細胞の種類」で学習させると、埋め込みは細胞型を強く表し、
**同一細胞型内の疾患差は相対的に小さくなる**（本ワークスペースの実測では 20.3% → 8.27%）。
この現象を「圧縮」と呼んでいます。

→ 状態対を選ぶ前に、**埋め込み空間での分離**を測ってください（[criteria.md](criteria.md) の C5）。

## 11. サブクラスタ（例: MG1 / MG2）

元論文が同じ細胞型をさらに分けた群。発現差が大きいことが多く、状態対として有望です
（実測例: MG1 vs MG2 の発現差 28.4% は AD vs 対照の 20.3% より大きい）。

## 12. 遺伝子リストの作り方

- **疾患リスク遺伝子**（GWAS など）
- **病態関連マーカー**（例: DAM マーカー）
- **炎症遺伝子**
- **陰性対照**（削除しても動かないはずの遺伝子: ACTB、GAPDH など）
- **陽性対照**（対象細胞で確実に発現している遺伝子。発現 0 の遺伝子は陽性対照にならない）

遺伝子は**シンボルで定義して辞書で Ensembl ID に解決**し、
**対象細胞で実際に発現しているものだけ**を使います（発現していなければ摂動できない）。

## 13. 用語の統一表（この Wiki で使う表記）

同じものを別の言葉で書くと読み手が迷うため、この表の左列を使います。右列は使いません。
初出の場所では、括弧内のように一度だけ意味を添えます。

| 使う表記 | 意味（初出で添える説明） | 使わない表記 |
|---|---|---|
| **ISP** | in silico perturbation の略。計算機上で遺伝子を操作する解析 | in-silico（ハイフン付き） |
| **Shift（Shift_to_goal_end）** | 遺伝子を削除したとき、細胞の状態が goal（例: WT）へどれだけ近づいたかを表す値 | シフト、シフト量 |
| **削除** | 遺伝子を1つ取り除く操作（この Wiki の基本操作） | KO（データ列名を除く）。実験操作の説明として「ノックアウト」は可 |
| **摂動できる細胞数** | その遺伝子のトークンを持ち、実際に削除操作の対象になった細胞の数（＝そのトークンを持つ細胞数） | 摂動対象細胞数、削除できる細胞数 |
| **検出率** | 対象の細胞のうち、その遺伝子を持っている細胞の割合 | 発現率 |
| **符号が反転する／符号の反転** | 同じ遺伝子で、2つの条件（モデル・組織・時点）の Shift の正負が食い違うこと | 符号が逆、符号反転 |
| **細胞型** | 単球・T 細胞などの区別（データ列名は `celltype` のまま） | 細胞集団、細胞種（混在させない） |
| **健常（WT）** | 比較の基準となる非疾患側 | 正常、コントロール（本文では使わない） |
| **疾患（AD／PD）** | アルツハイマー病／パーキンソン病。初出で日本語名を添える | — |
| **モデル（V2-104M／V2-316M）** | Geneformer の事前学習済みモデル。数字はパラメータ数 | 104M、316M（初出前の単独使用） |
| **モデル差** | モデルだけを替えたときの差 | — |
| **モデル依存** | 結果がモデルの選択で変わること | — |
| **数値精度（fp32／bf16）** | 計算に使う浮動小数点の形式 | dtype のみでの言及（初出時） |
| **分類器（CellClassifier）** | 細胞型を判定するために追加学習したモデル | ヘッド、probe（本文では使わない） |
| **C1〜C6** | 合格基準の番号。[合格基準](criteria.md)を参照 | 「基準」「しきい値」だけでの言及 |
| **ノイズ床（2.1e-04）** | 計算誤差だけで符号が変わりうる Shift の大きさ（§9） | 閾値、しきい値 |

表記に迷ったら、この表を先に更新してから各ページを直します（表が唯一の正）。
