## 1. 誰が書いてよいか

| 操作 | できる人 |
|---|---|
| 他人の受信箱に**追記**する | **誰でも可**（担当ページの規則の唯一の例外。依頼が届かないと分担が壊れるため） |
| 受信箱の既存行を**書き換える・消す** | その受信箱の持ち主**だけ** |
| 「状態」を「対応済み」に更新する | その受信箱の持ち主（依頼を処理した本人） |

**行は消しません。** 経緯が要るため、状態だけを更新して残します。

## 2. 書き方

受信箱に、次の形で**日付ごとの節**を追記します。

```markdown
## YYYY-MM-DD <呼び名> より

| # | 対象ページ | 直したい点 | 提案 | 根拠 | 状態 |
|---|---|---|---|---|---|
| 1 | conflicts.md | 参照が古い | 「§9」→「§E」 | style-guide.md の E-1 対応表 | 未対応 |
```

- **根拠**には、実測値・ファイル名・節を書きます。根拠のない依頼は受け取れません。
- 状態は **未対応 / 対応中 / 対応済み / 見送り（理由）** のいずれかです。
- 依頼が多くても、**対象ページごとに分けて**書きます。
